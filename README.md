# 🚗 Road Accident Analysis Dashboard

## 📊 Project Overview

An interactive Road Accident Analysis Dashboard built using Microsoft Excel to analyze accident trends, road conditions, vehicle types, and key performance indicators.

The project transforms raw road accident data into an interactive dashboard that helps identify accident patterns and understand the factors associated with road accidents.

## 🎯 Business Objective

The main objectives of this project are:

- Analyze overall road accident performance using key KPIs
- Identify monthly and yearly accident trends
- Analyze accidents by road type
- Analyze accidents by road surface condition
- Understand accident patterns across different categories
- Create an interactive dashboard for easy data-driven analysis
